### `Shopify Dynamics Junction`
This project is called **Shopify Dynamics Junction**. This is the frontend code of the application.

### `Product Short Description`
The frontend is build on Vuejs and is used to send order from Shopify to POS and to sycn inventory from POC to Shopify.

### `Product Technology/Framework`
Developed with Node wen framework **Vuejs**.

### `Product Modules`
1. Headless Application.
2. Retrieving Shopify Orders, Products.
3. Dynamic 365 Integration.
5. Order Posting Logs.
6. Order Posting Triggers.
7. Inventory Logs.
8. Inventory scheduler.

### `Installation Guide`
1. Clone the Repo to your directory.
2. Open the code folder in your IDE (eg. Sublime or Visual Studio Code)
3. Open up the directory in your terminal and install dependency by running
	- **`yarn install`**.
4. Start the server by:
	- **`yarn start`**
5. Go to **`http://localhost:8080/`** to visualize the project.
6. Make a production build by running
	- **`yarn build`**
