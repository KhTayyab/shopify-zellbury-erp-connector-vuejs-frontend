### `Shopify Zellbury ERP Connector`
This project is called **Shopify Zellbury ERP Connector**. This is the frontend code of the application.

### `Product Short Description`
The frontend is build on Vuejs and is used to send order from Shopify to POS and to sync inventory from POC to Shopify.

### `Installation Guide`
1. Clone the Repo to your directory.
2. Open the code folder in your IDE (eg. Sublime or Visual Studio Code)
3. Open up the directory in your terminal and install dependency by running
	- **`yarn install`**.
4. Start the server by:
	- **`yarn start`**
5. Go to **`http://localhost:8080/`** to visualize the project.
6. Make a production build by running
	- **`yarn build`**
